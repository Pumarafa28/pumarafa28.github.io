Código para hacer un análisis estadístico ANOVA y prueba de TUKEY

SQL, Python

Problema
Un ANOVA implica muchas operaciones repetitivas, y hacerlas a mano para cada tabla es lento y propenso a errores. Quería automatizarlo para que un solo código funcione con cualquier tabla, sin importar cuántas filas o columnas tenga.
Datos
El código lee cualquier tabla CSV. Lo probé con datos reales de un experimento en laboratorio en el área petrolera.
Hallazgos
Validé que los resultados coinciden con los calculos hechos a mano y con resultados publicados en papers.
-- Ejemplo de código

# ==========================================
# 3. ESTADÍSTICAS DESCRIPTIVAS
# ==========================================
resumen = (
    datos.groupby(columna_grupo)["Resultado"]
    .agg(
        n="count",
        Media="mean",
        Desviacion_estandar="std"
    )
    .reset_index()
)

Código para hacer un análisis estadístico ANOVA Y prueba de TUKEY

SQL, Python

Problema
¿Qué pregunta querías responder?
Datos
De dónde vienen y cuántos registros tienen.
Hallazgos
2 o 3 conclusiones concretas, con números.
-- Ejemplo de código
SELECT region, SUM(ventas) AS total
FROM pedidos
GROUP BY region
ORDER BY total DESC;
